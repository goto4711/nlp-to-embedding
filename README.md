# Term frequency vs. embeddings (Streamlit app)

app.py is a Streamlit app comparing term frequency with sentence embeddings, including keyword vs semantic
search. Streamlit Community Cloud deploys it from this repository: https://cdai-nlp-to-embedding.streamlit.app/

The web pages that used to live here (index.html and multimodal.html) have moved to the course site:
https://goto4711.github.io/cda-teaching-tools/tools/embeddings/ . The two files here now only forward visitors there.

**Used in:** Week 4 (Cultural Data Forms: Text).

## Files
app.py, requirements.txt, .streamlit/config.toml (colour theme); index.html and multimodal.html (forwarding pages);
cat.jpg, dog.jpg, car.jpg (kept so old links to the images still work).

## Running it
pip install -r requirements.txt, then streamlit run app.py.

Part of the teaching materials for Cultural Data Analysis, University of Amsterdam (Tobias Blanke).
